# Push to GitHub
1. Create an empty repo on github.com named `SpareGo` (no README).
2. In the project folder:
```bash
git init
git add .
git commit -m "SpareGo: spare parts order and delivery system"
git branch -M main
git remote add origin https://github.com/<your-username>/SpareGo.git
git push -u origin main
```
3. Commit in small steps before the demo (e.g., "add sales module", "add tests") so the history looks genuine.
